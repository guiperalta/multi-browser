# Quick Installation Guide

## Step 1: Install Node.js
- Go to [nodejs.org](https://nodejs.org/)
- Download and install the LTS version
- Restart your computer after installation

## Step 2: Setup the Application
1. Open Command Prompt or PowerShell
2. Navigate to the Multi Browser folder:
   ```
   cd "C:\Users\YourUsername\Desktop\multi-browser"
   ```
3. Run setup:
   ```
   node setup.js
   ```
4. Install dependencies:
   ```
   npm install
   ```

## Step 3: Run the Application
```
npm start
```

Or double-click `start.bat`

## Requirements
- ✅ Windows 10/11
- ✅ Google Chrome installed
- ✅ Node.js 16 or newer

## Quick Start
1. Enter a session name (e.g., "Personal")
2. Optionally enter a website URL
3. Click "Create Session"
4. Your browser will open in an isolated session
5. All data (cookies, logins, etc.) will be saved for next time!

## Need Help?
- Make sure Chrome is installed in the default location
- Try running as administrator if you get permission errors
- Check that Node.js is properly installed by running: `node --version`
